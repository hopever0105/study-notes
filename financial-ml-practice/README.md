# 금융 머신러닝·전략 실습

교재를 따라가며 주식 데이터(로컬 MySQL `stock_db`, 야후)로 직접 돌려 본 연습 코드. 전략 규칙을 코드로 옮기는 법, 성과 지표, 금융 시계열용 머신러닝 검증법을 익히는 게 목적이다.
여기서 익힌 방법론으로 만든 정식 전략·백테스트는 [quant-strategy-lab](https://github.com/hopever0105/quant-strategy-lab)에 따로 올린다.

> 연습용 코드다. 생존편향(현재 상위 종목을 과거에 적용)·미래정보 통제가 정식 검증 수준이 아니므로 결과 숫자를 성과로 쓰지 않는다.

## 파일

| 분야 | 파일 | 한 것 |
|---|---|---|
| 준비 | `공통환경_DB연결_머리말.txt` | 시드 고정, 한글 폰트, `.env`에서 DB 접속 정보 읽어 `load_sql()` 만들기 |
| 준비 | `금융 데이터 전처리 및 판다스.py`, `(수정본).py` | 판다스로 시세 다루기, 여러 열 선택 시 KeyError 예시와 고친 버전 |
| 준비 | `금융 데이터 open api 활용.py` | 공개 API로 시세·재무 받기 |
| 준비 | `금융 데이터 open ai 활용.py` | LLM API로 금융 텍스트 다루기 연습 (키는 환경변수) |
| 성과 측정 | `바이앤홀드 전략.py` | 국내(네이버)·미국(야후)·DB 시세 불러오기, 사서 들고 있기 누적수익 |
| 성과 측정 | `성과분석.py` | 31종목 CAGR·변동성·샤프·MDD 일괄 계산, 리스크-리턴 산점도 |
| 규칙 전략 | `듀얼모멘텀 전략.py` | 상대·절대·듀얼 모멘텀 개념, SPY 12개월 절대 모멘텀, 31종목 일괄 백테스트 |
| 규칙 전략 | `볼리저밴드 전략.py` | 볼린저 밴드 수식, 하단 이탈 매수·상단 이탈 청산, 31종목 고속 백테스트 |
| 규칙 전략 | `마법공식.py` | PER·ROA 순위 합산 상위 10종목 연 1회 리밸런싱 (DB 재무·시세) |
| 머신러닝 기초 | `금융ML기초_전처리_노이즈제거.py` | 금융 시계열의 한계, 노이즈 제거 5가지, MA·거래량 MA·RSI·CD금리 피처 만들기(쿠션 데이터) |
| 머신러닝 검증 | `금융ML_교차검증_레이블_백테스팅.py` | Walk-Forward·Blocking·Purging & Embargo 교차검증, `shift(-1)` 레이블, 샘플 가중치, 혼동행렬, 체결 시점·거래비용 반영 백테스트 |
| 지도학습 | `전략_KNN_SVM_단기방향성예측.py` | SPY 다음 날 방향 KNN, 스케일링 파이프라인 + KNN·SVM 비교(삼성전자) |
| 지도학습 | `전략_트리앙상블_시장트렌드예측.py` | SPY + GLD·TLT 피처 XGBoost 과적합 진단, TimeSeriesSplit + GridSearch, 정상성 피처 앙상블 백테스트 |
| 비지도학습 | `전략_클러스터링_종목분류_포트폴리오.py` | 미국 주식 수익률 패턴 K-means(엘보), 국내 대형주 100종목 멀티팩터 군집 + 분산 포트폴리오 |
| 이론 | `머신러닝 투자 활용 개요 - 설명과 실습 계획.md`, `알고리즘 트레이딩.txt` | 머신러닝 투자 활용 사례·개념 정리와 실습 계획 |

## 실행
Spyder(conda 환경 `ta_env`)에서 `#%%` 셀 단위로 실행. DB 접속 정보는 `quant/.env`에서 읽고 코드에 쓰지 않는다.
