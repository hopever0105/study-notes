규칙: Claude·검색 없이 혼자. 다 풀거나 30분 막히면 코드를 붙여 넣고 `/quant_practice 채점`.
각 문제는 함수 하나를 완성하면 된다. 아래 입력 예시 말고 다른 입력(숨은 테스트)에서도 맞아야 한다.

## 문제 1. 등락 표시 달기

당일 등락률(%) `change`가 주어진다. 아래 규칙대로 글자를 돌려주는 함수 `label(change)`를 만드세요.

| 조건 | 돌려줄 글자 |
|---|---|
| change가 5 이상 | `"급등"` |
| change가 0보다 크고 5보다 작음 | `"상승"` |
| change가 0 | `"보합"` |
| change가 -5 이하 | `"급락"` |
| 그 밖 (-5보다 크고 0보다 작음) | `"하락"` |

제한
- change는 -30 이상 30 이하의 실수(소수점 있을 수 있음)

| 입력 | 출력 |
|---|---|
| `label(7.2)` | `"급등"` |
| `label(5)` | `"급등"` |
| `label(0)` | `"보합"` |
| `label(-1.5)` | `"하락"` |
| `label(-5)` | `"급락"` |

## 문제 2. 주문 종류 세기

하루 동안 들어온 주문 종류가 리스트 `orders`로 주어진다. 원소는 `"매수"`, `"매도"`, `"취소"` 셋 중 하나다.
종류별 개수를 딕셔너리로 돌려주는 함수 `count_orders(orders)`를 만드세요.

제한
- orders 길이는 1 이상 100 이하
- **한 번도 안 나온 종류는 딕셔너리에 넣지 않는다.**
- 딕셔너리 안 순서는 채점하지 않는다.

| 입력 | 출력 |
|---|---|
| `count_orders(["매수", "매도", "매수", "취소", "매수"])` | `{"매수": 3, "매도": 1, "취소": 1}` |
| `count_orders(["매도", "매도"])` | `{"매도": 2}` |

---

## 문제 3. 종목별 순매수 수량

체결 기록이 리스트 `trades`로 주어진다. 원소 하나는 `"종목명 방향 수량"` 모양의 문자열이다 (띄어쓰기 한 칸으로 구분).
- 방향은 `"매수"` 또는 `"매도"`
- 수량은 1 이상 1000 이하 정수(문자열로 들어 있음)

종목별 순매수 수량(매수 합 − 매도 합)을 딕셔너리로 돌려주는 함수 `net_by_stock(trades)`를 만드세요.

제한
- trades 길이는 1 이상 100 이하
- 종목명에는 띄어쓰기가 없다.
- 순매수가 0이 된 종목도 딕셔너리에 `0`으로 남긴다.
- 딕셔너리 안 순서는 채점하지 않는다.

| 입력 | 출력 |
|---|---|
| `net_by_stock(["삼성전자 매수 10", "SK하이닉스 매수 5", "삼성전자 매도 3"])` | `{"삼성전자": 7, "SK하이닉스": 5}` |
| `net_by_stock(["NAVER 매도 4", "NAVER 매수 4"])` | `{"NAVER": 0}` |
| `net_by_stock(["카카오 매도 2"])` | `{"카카오": -2}` |
