## 문제 4. 종가 상위 3개

며칠 동안의 종가가 리스트 `closes`로 주어진다. 큰 값부터 3개를 리스트로 돌려주는 함수 `top3(closes)`를 만드세요.

제한
- closes 길이는 3 이상 100 이하, 원소는 1 이상 1,000,000 이하 정수
- 같은 값이 여러 개면 그만큼 다 센다.
- **입력 리스트 closes 자체의 순서는 바꾸지 않는다.**

| 입력 | 출력 |
|---|---|
| `top3([70000, 72000, 69000, 75000, 71000])` | `[75000, 72000, 71000]` |
| `top3([500, 500, 300, 100])` | `[500, 500, 300]` |

## 문제 5. 최근 n일 평균

날짜순(오래된 날 → 최근 날)으로 종가 리스트 `closes`와 정수 `n`이 주어진다. **마지막 n개** 종가의 평균을 돌려주는 함수 `recent_mean(closes, n)`을 만드세요.

제한
- closes 길이는 1 이상 100 이하, 원소는 1 이상 1,000,000 이하 정수
- n은 1 이상 closes 길이 이하
- 평균은 나눗셈(`/`) 결과 그대로 돌려준다 (반올림하지 않음).

| 입력 | 출력 |
|---|---|
| `recent_mean([100, 110, 120, 130], 2)` | `125.0` |
| `recent_mean([100, 110, 120, 130], 4)` | `115.0` |
| `recent_mean([50], 1)` | `50.0` |

## 문제 6. 거래대금 순위

종목별 거래대금(억 원)이 딕셔너리 `amounts`로 주어진다. 거래대금이 **큰 종목부터** 종목명을 리스트로 돌려주는 함수 `rank_by_amount(amounts)`를 만드세요.

제한
- 종목 수는 1 이상 50 이하
- 거래대금은 1 이상 100,000 이하 정수, **서로 같은 값은 없다.**

| 입력 | 출력 |
|---|---|
| `rank_by_amount({"삼성전자": 1500, "카카오": 300, "NAVER": 800})` | `["삼성전자", "NAVER", "카카오"]` |
| `rank_by_amount({"현대차": 50, "기아": 70})` | `["기아", "현대차"]` |
| `rank_by_amount({"LG화학": 10})` | `["LG화학"]` |
