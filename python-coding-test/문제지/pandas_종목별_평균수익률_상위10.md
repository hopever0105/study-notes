## 먼저 알아 둘 것 (다른 소재 예시)

**1. 정렬: `sort_values`** — 여러 열 기준이면 리스트로
```python
s = pd.DataFrame({'반': ['2반', '1반', '1반'], '번호': [1, 2, 1]})
s.sort_values(['반', '번호'])        # 1반 1번 → 1반 2번 → 2반 1번
```

**2. 앞 행 대비 변화율: `pct_change`**
```python
pd.Series([100, 110, 99]).pct_change()   # [NaN, 0.10, -0.10]   (110/100-1, 99/110-1)
```
첫 행은 앞 행이 없어서 NaN(빈칸).

**3. 묶어서 계산: `groupby`**
```python
s = pd.DataFrame({'반': ['1반', '1반', '2반'], '점수': [80, 90, 70]})
s.groupby('반')['점수'].mean()            # 1반 85.0, 2반 70.0
s.groupby('반')['점수'].pct_change()      # 반 안에서만 앞 행과 비교 → [NaN, 0.125, NaN]
```
`groupby` 없이 `pct_change`를 하면 1반 마지막 행과 2반 첫 행을 이어서 계산해 버린다.

**4. 큰 순서로 k개: `sort_values(ascending=False).head(k)`** 또는 `nlargest(k)`

## 문제

함수 `top_mean_return(df, k)`를 만든다.

- 입력 `df`: 열이 `date`(날짜), `code`(종목코드 문자열), `close`(종가)인 표. **행 순서가 섞여 있을 수 있다.**
- 일별 수익률 = 오늘 종가 / **같은 종목의** 전 거래일 종가 − 1
- 각 종목의 첫 날은 전날이 없으므로 수익률 계산에서 빠진다(평균에 넣지 않음).
- 종목별 일별 수익률의 **평균**을 구해, 큰 순서로 `k`개를 돌려준다.
- 돌려주는 값: 인덱스가 `code`, 값이 평균 수익률(소수 넷째 자리 반올림)인 Series.

### 예시 1
입력 (행 순서 섞임):

| date | code | close |
|---|---|---|
| 2026-01-03 | A | 99 |
| 2026-01-01 | A | 100 |
| 2026-01-02 | A | 110 |
| 2026-01-03 | B | 55 |
| 2026-01-01 | B | 50 |
| 2026-01-02 | B | 50 |
| 2026-01-03 | C | 20.9 |
| 2026-01-01 | C | 20 |
| 2026-01-02 | C | 19 |

`top_mean_return(df, 2)` →
```
code
B    0.050
C    0.025
```
(A: +10%, −10% → 평균 0 / B: 0%, +10% → 0.05 / C: −5%, +10% → 0.025)

### 예시 2
같은 입력, `top_mean_return(df, 1)` →
```
code
B    0.05
```

### 예시 3 (틀리면 이렇게 나온다)
