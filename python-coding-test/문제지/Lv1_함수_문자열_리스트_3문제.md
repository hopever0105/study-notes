## 먼저 알아 둘 것 (예시)

**1. 함수 만들기: `def` + `return`**
```python
def double(x):
    return x * 2

double(5)   # 10
```
`return`은 함수 밖으로 값을 돌려보내는 줄. 함수 안 `for`가 끝난 뒤에 두어야 한다(for 안에 두면 첫 바퀴에 끝남).

**2. 문자열 쪼개기: `split`**
```python
'005930 매수 10'.split(' ')    # ['005930', '매수', '10']
int('10') + 1                  # 11  (문자열 '10'은 숫자로 바꿔야 계산됨)
```

**3. 딕셔너리에 값 더하기 (개수 세기 응용)**
```python
total = {}
for code, qty in [('005930', 3), ('005930', 4)]:
    if code in total:
        total[code] = total[code] + qty     # 있으면 더하기
    else:
        total[code] = qty                   # 없으면 새로 넣기
total   # {'005930': 7}
```

## 문제 1. 연속 상승 최장 길이

함수 이름: `longest_up_streak(closes)`
- 입력 `closes`: 종가 리스트 (정수, 길이 1 이상)
- 출력: 전날보다 오른 날이 **연속으로** 몇 번 이어졌는지의 최댓값
- 예시
  - `longest_up_streak([100, 101, 102, 101, 103, 104, 105, 99])` → `3` (103→104→105)
  - `longest_up_streak([5, 4, 3])` → `0`
- 조건: 같은 가격(보합)은 오른 것이 아니다. 반복문 한 번만 쓸 것.

## 문제 2. 종목별 순매수 수량

함수 이름: `net_buy_by_code(logs)`
- 입력 `logs`: 문자열 리스트. 한 줄 형식은 `"종목코드 매수|매도 수량"` (예: `"005930 매수 10"`)
- 출력: 딕셔너리 `{종목코드: 순매수 수량}`. 매수는 +, 매도는 -
- 예시
  - `net_buy_by_code(["005930 매수 10", "000660 매도 5", "005930 매도 3"])` → `{'005930': 7, '000660': -5}`
  - `net_buy_by_code([])` → `{}`
- 조건: 종목코드는 문자열 그대로 둔다(`'000660'`의 앞자리 0이 사라지면 안 됨). 수량은 `int`로 바꿔서 계산.

## 문제 3. 거래량 가중 평균가 (VWAP)

함수 이름: `vwap(trades)`
- 입력 `trades`: `(체결가, 체결수량)` 튜플의 리스트
- 출력: `(체결가 × 수량)의 합 ÷ 수량의 합`, 소수점 둘째 자리에서 반올림(`round(값, 2)`)
- 예시
  - `vwap([(100, 10), (200, 30)])` → `175.0`  ((1000 + 6000) / 40)
  - `vwap([(50, 1), (60, 1)])` → `55.0`
  - `vwap([])` → `None` (체결이 하나도 없으면 계산하지 않고 `None`)
- 조건: `for` 한 번으로 두 합을 같이 구할 것. 수량 합이 0이면 나누기 전에 `None`.
