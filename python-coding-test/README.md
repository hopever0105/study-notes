# 파이썬 코딩테스트 공부

퀀트 회사 코딩 시험(알고리즘 문제)을 준비하며 단원별로 정리한 코드.
알고리즘 문제는 시험 환경에 맞춰 **패키지 없이 기본 파이썬만** 쓴다. pandas 분석은 별도 폴더에서.

## 단원

| 단원 | 배우는 것 | 파일 |
|---|---|---|
| 01 기초문법 | 변수, `=`(넣기)와 `==`(같은지 묻기), `+=`, f-문자열(`f"{n:05d}"`), 리스트 `append`, 함수 `def`·`return`, 문자와 숫자(`str`·`int`) | `01_기초문법/기초문법_리스트_반복문_문자열_함수.py`, `01_기초문법/문법_등호1개_2개.py` |
| 02 반복문·리스트 | `range(1, len(x))`로 바로 앞 값과 비교, 조건에 맞는 개수 세기 | `02_반복문_리스트/문제_오른날세기.py` |
| 03 문자열 | `zfill`로 앞자리 0 채우기, `split(",")`로 쪼개기, `p[0]`·`p[1:]` 자르기 | `03_문자열/문제_종목코드6자리.py`, `03_문자열/문제_순매수수량.py` |
| 04 조건문 | `if`·`elif`·`else`, 한 줄 if, `math.gcd`로 약분, `/`와 `//` 차이 | `04_조건문/프로그래머스_숫자비교하기.py`, `04_조건문/프로그래머스_분수의덧셈.py` |

다음 단원(예정): 05 정렬 → 06 스택·큐 → 07 그리디·구현 → 08 DFS·BFS → 09 이진탐색 → 10 동적계획법

## 문제 파일 구성
각 문제 파일은 위에 문제(조건·예시), 아래 `#%%` 구역에 내 풀이가 있다. Spyder에서 `Ctrl+Enter`로 구역별 실행.

## 틀렸던 것
| 단원 | 실수 | 고친 방법 |
|---|---|---|
| 02 | 예시 답만 맞추면 된다고 생각 (길이 5면 2를 반환) | 채점기는 숨은 테스트를 넣는다 → 어떤 입력에도 맞는 규칙(반복문)을 짠다 |
| 03 | `for x in []` — 입력 대신 빈 리스트를 돌림 | 함수 입력 이름(`codes`)을 그대로 돌린다 |
| 03 | 문자열을 `split` 없이 `for`로 돌림 → 한 글자씩 나옴 | `for p in orders.split(","):` |
| 03 | `return`을 `for` 안에 둠 → 첫 바퀴에서 끝남 | `return`은 `for`와 같은 높이(반복이 끝난 뒤) |
| 04 | `else` 뒤에 조건을 붙임 (`else num1 != num2:`) → SyntaxError | `else:`는 조건 없이, 조건이 필요하면 `elif` |
| 04 | `math.gcd()` 괄호를 비워 둠 → 0이 나와 0으로 나누기 에러 | `math.gcd(top, bottom)`처럼 재료를 넣는다 |

## 문제 출처
문제지는 프로그래머스 Lv.0 유형을 참고해 주가·주문 소재로 직접 만든 것(`문제지/`).
연습: 프로그래머스 '코딩테스트 입문' 100문제(Day 1~25). 프로그래머스 문제는 원문 대신 한두 줄 요약만 적음.

## 정리 방식
공부 파일은 `정리전/`에 모아 두고 일주일에 한 번 단원별로 옮겨 이 저장소에 올린다.
