교재 원본 코드·데이터는 올리지 않았다.

| 장 | 절 | 파일 | 한 것 |
|---|---|---|---|
| 2장 데이터 핸들링 | 2-1 데이터 불러오기와 기본 구조 | `02_데이터핸들링/2-1 데이터 불러오기와 기본 구조 이해.py` | 종목명·가격으로 데이터프레임 만들기, csv 저장·읽기, `info`·`describe`·`dtypes`, `astype`, `set_index`·`reset_index`, 열 이름 바꾸기 |
| 4장 통계분석 | 4-2 모수 추정과 신뢰구간 | `04_통계분석/4-2 모수 추정과 신뢰구간.py` | 삼성전자 2025년 일간 수익률 평균의 95% 신뢰구간(t분포), 오른 날 비율의 95% 신뢰구간(정규근사) + 교재 예제(배송시간·불량률) |

## 4-2 결과 (삼성전자 2025년, 242거래일)
| 추정 대상 | 점추정 | 95% 신뢰구간 | 해석 |
|---|---|---|---|
| 평균 일간 수익률 | 0.36% | [0.09%, 0.63%] | 구간이 0보다 위 → 평균적으로 오른 해 |
| 오른 날 비율 | 54.1% | [47.9%, 60.4%] | 50%를 포함 → 오른 날이 더 많다고 말할 수 없음 |

평균은 플러스가 확실한데 오른 날 비율은 반반과 구별이 안 된다 → 상승은 "자주"보다 "크게" 오른 데서 나왔다.
