# my-python-quant-study

파이썬으로 퀀트 투자 과정을 처음부터 끝까지 따라가며 정리한 실습 코드입니다.
**파이썬 기초 → 크롤링 → 국내·해외 데이터 수집(MySQL 저장) → 팩터 전략 → 종목 선정 → 포트폴리오 최적화 → 백테스트 → 기술적 지표 → 증권사 API** 순서로 15개 파일에 쌓았습니다.

## 실행 환경

- Python 3, Spyder/VS Code의 `#%%` 셀 단위 실행
- 04~13장은 로컬 MySQL(`stock_db`)에 쌓은 데이터를 씁니다.
- 비밀번호·API 키는 코드에 적지 않고 환경변수(`DB_PW`, `KRX_ID`, `KRX_PW`)나 `keyring`에 저장해 불러옵니다.
- 15장은 한국투자증권 모의투자 서버를 기준으로 작성했습니다.

## 사용 패키지

`pandas` · `numpy` · `requests` · `beautifulsoup4` · `selenium` · `pykrx` · `sqlalchemy` · `pymysql` · `yfinance` · `tiingo` · `pandas_datareader` · `keyring` · `statsmodels` · `matplotlib` · `seaborn` · `riskfolio-lib` · `bt`
